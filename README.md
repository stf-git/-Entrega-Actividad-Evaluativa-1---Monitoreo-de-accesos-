# Actividad Evaluativa #1: Centro de Monitoreo de Accesos
**Asignatura:** Programación Orientada a Objetos — 2.º curso (Ciberseguridad)  
**Institución:** ENTI - Universitat de Barcelona  

## Descripción
Programa en Java que evalúa y clasifica los registros de autenticación de dos servidores independientes (VPN, Web, Correo, etc.), calcula el porcentaje de fallos y determina la prioridad de atención operativa en función de reglas de criticidad y riesgo.

## Estructura del Repositorio
* `Main.java`: Código fuente completo con las clases `Servidor` y `Main`, además de las preguntas conceptuales.
* `reporte.tex`: Código fuente en LaTeX del informe técnico.
* `reporte.pdf`: Reporte técnico compilado.

## Compilación y Ejecución
Para compilar y ejecutar el sistema desde la terminal:

```bash
javac Main.java
java Main
